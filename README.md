# Torc Union — The AI Union Engine

An AI-powered platform for worker empowerment and cooperative strategic decision-making.

## MVP: CEO Extraction Calculator

Enter your company's CEO compensation, employee count, and your own salary to see what fair redistribution would mean for your paycheck — monthly, weekly, and in concrete life terms.

## Tech Stack

- Pure HTML / CSS / JavaScript — no frameworks, no build step
- Mobile-responsive, WCAG 2.1 AA compliant
- Zero runtime dependencies, fast load everywhere

## File Structure

```
├── index.html        Landing page and calculator interface
├── styles.css        Design system and all styles
├── calculator.js     Calculator logic and UI behavior
├── assets/
│   └── icons/        SVG icons (if needed)
└── README.md
```

## Running Locally

```bash
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

No server required. Works directly from the filesystem.
